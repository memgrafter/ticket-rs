# Add ticket file validation

Add a validation command (tk validate <id>) that checks ticket files for correctness before writing them.

Currently tk create just writes YAML frontmatter + markdown body without any validation. This means:
- Invalid YAML in frontmatter (e.g., unescaped special characters in description) silently produces broken tickets
- Missing required fields (status, deps, etc.) are not caught
- Typos in field names or values are not detected

Validation should check:
1. YAML frontmatter is valid and parseable
2. Required fields present: id, status, deps, links, created, type, priority, assignee, tags
3. Status values are valid: open, in_progress, closed
4. Type values are valid: bug, feature, task, epic, chore
5. Priority is 0-4
6. Deps/links reference valid ticket IDs

This would catch the bash escaping issue (description with , (), <> gets mangled before reaching tk) and other common mistakes.
